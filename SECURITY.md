# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

The Kavach team takes the security of cryptographic payment delegation seriously. If you discover a vulnerability or bypass in the Kavach policy engine, interceptor, or gateway verification:

1. **Do not create a public issue on GitHub.**
2. Send an email to `security@kavach.ai` (or via private advisory) with:
   - Detailed description of the bypass or cryptographic flaw.
   - Minimal reproducible proof-of-concept (Python script or curl commands).
   - The impact on financial mandate boundaries.
3. We will respond within 48 hours to acknowledge receipt and coordinate a fix.
